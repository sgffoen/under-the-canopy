# RhinoCopilot: Installation & Usage Guide

Welcome to **RhinoCopilot**, your AI-powered companion inside Rhino. Follow this quick guide to install the plugin and start streamlining your 3D modeling and rendering workflows.

---

## 🚀 Installation Steps

Getting RhinoCopilot up and running is quick and straightforward:

1. **Download the Plugin Files**: Download the provided `.rhp` files for RhinoCopilot.
2. **Install via Drag-and-Drop**: 
   - Open your active instance of Rhinoceros (Rhino).
   - Locate the downloaded `.rhp` file on your computer.
   - Drag the `.rhp` file and drop it directly into any active Rhino viewport or workspace.
3. **Completion**: In Rhino, type "RhinoCopilot" in command prompt window then, load the plugin. You are now ready to go!

## 💡 How to Use RhinoCopilot

RhinoCopilot features an intuitive dual-interface system designed to assist with both computational design logic and visualization.

### 1. Chat Window
* **Purpose**: General AI assistance, command generation, troubleshooting, and workflow optimization.
* **How to use**: Simply open the Chat window interface and ask whatever you want (e.g., *"How do I rebuild a surface with clean topology?"* or *"Give me a Python script to array objects along a curve"*).

### 2. Render Window
* **Purpose**: AI-driven rendering, look-development, and viewport enhancement.
* **How to use**:
  1. Open the RhinoCopilot Render window.
  2. Set up your Rhino viewport carefully (adjust the camera angle, perspective, and framing).
  3. Click the **Capture Viewport** button. This will capture and upload your current view to the AI engine.
  4. Type your rendering prompt to describe the desired materials, atmospheric conditions, or stylistic directions (e.g., *"Modern concrete villa during golden hour, photorealistic"*).
  5. The plugin will process the request and generate your stylized render.

## ⚠️ Important Limitations
* **Multiple Instances**: **Do not try to open two instances of Rhino.**
* **System Conflict**: Running multiple Rhino windows simultaneously will cause the system to get confused and may break the AI connection.
